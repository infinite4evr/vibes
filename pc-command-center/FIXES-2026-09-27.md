# Reliability + UI fix pass — 2026-09-27

This build incorporates the complete responsive UI audit already present in `docs/UI-AUDIT-2026-09-26.md` and fixes the runtime issues found during the follow-up execution/code audit.

## Runtime fixes
- Battery probing is now optional/fail-safe when psutil raises `OSError`, `FileNotFoundError`, `AttributeError`, or `NotImplementedError`.
- Weekly maintenance now checks external-command return codes and no longer records failed cleanup steps as `ok`.
- Trash-size alert scanning tolerates files disappearing or becoming unreadable during the scan.
- Journald parsing skips records with malformed timestamp/priority numeric fields instead of aborting the complete log view.
- `pc awake` duration parsing now rejects partial/garbage values such as `abc2hxyz` and `2hours`.
- Generated maintenance/watch systemd `ExecStart=` lines now use the project's systemd-safe command quoting.

## UI fixes included
The current tree includes the full responsive UI pass across all 16 GTK pages: wrapping page headers/action bars/filters, compact-window margins, content-aware sidebar sizing, compact search access, command-palette de-duplication, adaptive charts, safer page-construction fallback, smaller laptop-friendly dialogs, icon-button accessibility labels/tooltips, and responsive layouts on Dashboard, Cleanup, Updates, Apps, Startup, Processes, Storage, Network, Power, Logs, Services, Security, Privacy, Tweaks, Developer, and Maintenance.
