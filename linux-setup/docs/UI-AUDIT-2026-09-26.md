# UI Audit & Fix Pass — 2026-09-26

**Release:** 2.2.1  
**Scope:** PC Command Center GTK 4/libadwaita desktop UI  
**Goal:** inspect every primary page and its high-density options/actions, remove clipping/overflow/duplication problems, preserve the resizable sidebar, and replace slide motion with gentler animation.

## Executive summary

The app already had a strong visual foundation, but a repeated layout pattern caused many of the visible bugs: controls were placed in rigid horizontal `Gtk.Box` rows even though the main window and sidebar are both resizable. Those rows worked at the default size but could clip buttons, crush labels, or force awkward spacing at compact widths. The fix is systemic rather than resolution-specific: reusable wrapping layouts are now used for action bars, filters, hero controls, and other dense rows.

The shell also had one functional UI defect: the Ctrl+K command-palette dialog inserted the complete action registry twice, producing duplicate choices. That duplicate insertion is removed.

## Shared shell / global UI fixes

- **Gentle motion instead of slide motion:** page changes and sidebar show/hide now use a restrained crossfade. Motion preference values are Full = 180 ms, Reduced = 90 ms, Off = 0 ms.
- **Resizable sidebar protection:** sidebar width is clamped to a useful range and dynamically leaves room for page content, preventing the sidebar from crushing the active page at compact window sizes.
- **Sidebar status card:** long disk/memory text wraps and the cleanup link gets its own line.
- **Quick actions:** fills the sidebar width consistently instead of looking like a floating, undersized control.
- **Header search:** lower minimum width and a popover width derived from the current window, avoiding overflow on smaller windows.
- **Command palette:** removed duplicated action rows.
- **Reusable responsive layout helper:** `flow()` now provides a standard wrapping action/filter layout used throughout the application.
- **Page headers:** header actions wrap instead of pushing/cropping the page title.
- **Banners:** warning/info/action banners can wrap their text and buttons instead of clipping.
- **Horizontal bar charts:** label and value gutters adapt to the actual allocated width; labels ellipsize based on the current width instead of assuming a large fixed gutter.
- **Tabs:** existing automatic compact tab behavior is preserved and now benefits from the wider responsive pass.

## Validation note

This pass combines source-level UI inspection with the existing automated suite. Actual GTK pixel rendering could not be performed inside this container because the required `gi` GTK/libadwaita Python bindings are absent. The repository's GTK/Xvfb smoke test remains the authoritative final renderer check on an Ubuntu environment with those packages installed.

## Handover guidance

This is a **replacement build** for the previous 2.2.0 source tree. User preferences/state live outside the repository under the normal per-user config/state locations, so replacing the source folder does not require merging these UI source files one-by-one. If local source-code customizations were made after 2.2.0, diff/merge those custom changes instead of overwriting them blindly.
