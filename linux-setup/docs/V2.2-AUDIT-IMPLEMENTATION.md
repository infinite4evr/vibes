# v2.2 audit implementation

This release focuses on high-impact audit findings rather than adding unsafe breadth.

## Implemented

- Exact privileged-batch return-code policy.
- Private 0600 admin batches and stricter pc-admin validation.
- Secret-aware command rendering and best-effort global redaction.
- Opt-in rotating debug logs and redacted support bundles.
- Background task registry/UI with command cancellation and scheduled-job controls.
- Process-group cancellation plus safe-stop behavior for package/boot/filesystem operations.
- Resizable/collapsible persistent sidebar.
- Animated navigation/sidebar with Full, Reduced and Off motion modes.
- Hardened restore extraction and automatic pre-restore backup.
- Safer swap resize with staged replacement and rollback.
- Atomic/private state in activity, preferences, alerts, health history, maintenance, cleanup history, antivirus logs and custom user units.
- HTTPS/TLS-only bootstrap fetches and downloaded-script syntax validation.
- Safer uv install fallback without a pipe-to-shell path.
- Test ergonomics and new privileged-execution/redaction/task tests.

## Deliberately not automated

Some audit ideas require distribution-specific integration or physical-hardware validation (for example a root D-Bus daemon replacing shell batches, kernel/firmware rollback, destructive drive operations, and hardware benchmark tuning). Those should not be silently introduced without a dedicated integration environment. The code now has safer foundations for those future additions.
